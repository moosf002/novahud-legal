สำหรับ NovaHUD

ปรับปรุงล่าสุด: 20 ตุลาคม 2026

1. วัตถุประสงค์ของ NovaHUD

NovaHUD เป็นแอปพลิเคชันสำหรับตรวจสอบประสิทธิภาพและแสดงข้อมูลแบบ HUD บนอุปกรณ์ Android

ฟังก์ชันที่รองรับขึ้นอยู่กับอุปกรณ์ สิทธิ์ เวอร์ชัน Android ความพร้อมของ Shizuku และการทำงานของเกม เช่น

  • FPS ทั่วไป
  • GAME FPS ในระบบที่รองรับ
  • ข้อมูล RAM
  • ข้อมูลแบตเตอรี่
  • ข้อมูลอุณหภูมิ
  • ข้อมูลอุปกรณ์
  • ประวัติและกราฟ FPS
  • การปรับแต่ง HUD
  • การตรวจจับเกมอัตโนมัติ
  • การปรับแต่งเพิ่มเติมสำหรับ NovaHUD Premium

2. ความเข้ากันได้

NovaHUD ออกแบบมาสำหรับอุปกรณ์ Android ที่รองรับ แต่ผลการทำงานอาจแตกต่างตาม:

  • ผู้ผลิตอุปกรณ์
  • เวอร์ชัน Android
  • เฟิร์มแวร์และระบบของผู้ผลิต
  • เกมและแอป
  • ระบบกราฟิกและ API
  • เวอร์ชันและความพร้อมของ Shizuku
  • ข้อจำกัดการทำงานเบื้องหลังของอุปกรณ์

เราไม่รับประกันว่าทุกฟังก์ชันจะทำงานได้กับทุกอุปกรณ์หรือทุกเกม

โดยเฉพาะ GAME FPS อาจขึ้นอยู่กับเกม พฤติกรรมของ Android สิทธิ์ที่อนุญาต และ Shizuku

3. FPS ทั่วไปและ GAME FPS

FPS ทั่วไปและ GAME FPS เป็นโหมดการวัดที่แตกต่างกัน และอาจให้ผลลัพธ์ไม่เท่ากัน

NovaHUD พยายามแสดงชนิดและแหล่งที่มาของ FPS ตามข้อมูลที่ระบบรองรับอย่างถูกต้อง

ค่าประสิทธิภาพที่แสดงมีวัตถุประสงค์เพื่อให้ข้อมูล ไม่ใช่ผลการวัดที่ผ่านการรับรองจากห้องปฏิบัติการ

4. สิทธิ์ของระบบ

NovaHUD ใช้สิทธิ์แสดงทับแอปอื่น (Overlay) เพื่อแสดง HUD บนหน้าจอเกมหรือแอปอื่น

Basic HUD แบบ Manual ไม่จำเป็นต้องใช้ Shizuku หรือ Usage Access ส่วน Basic HUD ที่เปิด Auto Detection ต้องได้รับสิทธิ์ Usage Access สำหรับ True GAME FPS ต้องมีทั้ง Shizuku ที่เชื่อมต่อพร้อมใช้งานและสิทธิ์ Usage Access ไม่ว่าจะเริ่มแบบ Manual หรือ Auto Detection

ผู้ใช้สามารถปฏิเสธสิทธิ์ที่ไม่จำเป็นต่อโหมดที่เลือกได้ แต่ฟังก์ชันที่ต้องใช้สิทธิ์ดังกล่าวจะไม่สามารถทำงานได้จนกว่าจะได้รับสิทธิ์ครบตามเงื่อนไข การให้สิทธิ์ครบไม่ได้รับประกันว่าเกมและอุปกรณ์ทุกประเภทจะรองรับการวัด GAME FPS

5. Auto Detection

Auto Detection เป็นฟังก์ชันที่ผู้ใช้เลือกเปิดหรือปิดได้ โดยค่าเริ่มต้นของการติดตั้งใหม่คือปิด ผู้ใช้สามารถเริ่ม Basic HUD แบบ Manual ได้โดยไม่ต้องใช้ Usage Access

เมื่อเปิด Auto Detection จะต้องมีสิทธิ์ Usage Access เพื่อให้ NovaHUD ตรวจจับเกมที่เลือกได้ ส่วน True GAME FPS ต้องใช้ทั้ง Usage Access และ Shizuku ไม่ว่าจะเปิดหรือปิด Auto Detection

การตั้งค่าการทำงานเบื้องหลังหรือข้อจำกัดการใช้แบตเตอรี่ของอุปกรณ์อาจส่งผลต่อความต่อเนื่องของ HUD โดยพฤติกรรมอาจแตกต่างกันตามผู้ผลิตอุปกรณ์และเวอร์ชัน Android

6. NovaHUD Premium

NovaHUD Premium เป็นการซื้อภายในแอปแบบครั้งเดียวผ่าน Google Play

Premium อาจปลดล็อกฟังก์ชันการปรับแต่งขั้นสูงและฟังก์ชัน Premium อื่นตามที่แสดงภายในแอป

การซื้อ Premium ไม่ได้หมายความว่าทุกอุปกรณ์ ทุกเกม หรือ GAME FPS ทุกกรณีจะรองรับการทำงาน

7. การซื้อ

การชำระเงินดำเนินการผ่าน Google Play

ราคา สกุลเงิน ภาษี ความพร้อมในการซื้อ และวิธีชำระเงินอยู่ภายใต้ระบบของ Google Play และกฎหมายที่เกี่ยวข้อง

NovaHUD ไม่ประมวลผลข้อมูลบัตรชำระเงินของผู้ใช้โดยตรง

8. การคืนเงิน

สิทธิ์และเงื่อนไขการคืนเงินอยู่ภายใต้นโยบายของ Google Play และกฎหมายที่ใช้บังคับ

ผู้ใช้อาจขอคืนเงินผ่านช่องทางของ Google Play หรือสอบถามผู้พัฒนาในกรณีที่เกี่ยวข้อง

การคืนสิทธิ์ขึ้นอยู่กับบริการ Google Play บัญชี Google ที่ใช้ซื้อ และข้อมูลการซื้อที่ Google Play มีอยู่

  • อ้างว่า NovaHUD เป็นผลิตภัณฑ์ของตนเองโดยไม่ได้รับอนุญาต
  • แจกจ่ายสำเนาที่แก้ไขหรือไม่ได้รับอนุญาตโดยละเมิดสิทธิ์ที่เกี่ยวข้อง
